# TSS V29 — Protótipo UX Fase 1

Protótipo isolado do sistema atual. Não altera `index.html`, GitHub Pages nem os dados da V28.

## Telas incluídas

1. Painel inicial
2. Central de validação
3. Prontuário da pessoa
4. Portaria

## Objetivo

Validar a experiência antes da integração com Supabase e antes de modificar a versão em produção.

## Como testar

Abra `prototype-v29/index.html` em um navegador.

O protótipo usa dados fictícios e contém navegação, filtros, abas, ações simuladas e layout responsivo.

## Critérios de validação

- O usuário entende a próxima ação?
- A informação crítica aparece em menos de 10 segundos?
- O sistema explica o motivo do bloqueio?
- A portaria consegue decidir sem abrir vários módulos?
- A linguagem é compreensível para usuários não técnicos?

## Fora do escopo nesta etapa

- Banco de dados real
- Login
- Upload de arquivos
- Envio de notificações
- Integração com Supabase
- Alteração do aplicativo atual
